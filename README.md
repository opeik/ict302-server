## Building

- [Install Rust](https://www.rust-lang.org/tools/install)

Clone repository:

```
git clone https://10.51.33.18/alpha-squad/server.git
```

Build:

```
cargo build
```

Run:

```
RUST_LOG=warn,info,debug cargo run
```
